# Wavora

Live streaming and social app: watch creators, send gifts, chat, and go live.

## What's in here

- `index.html`: the test version that runs in any phone browser. Turn on GitHub Pages and it gets its own link.
- `app/`: the React Native (Expo) code for the real Android and iPhone app. Setup steps are in `app/README.md`.

## Test link

Once GitHub Pages is on, the app is at:

`https://YOUR-USERNAME.github.io/wavora/`

Everything is simulated: no real video, accounts or payments yet. Each tester's Sparks, messages and profile are saved only in their own browser.

## Testing checklist

- [ ] Sign up, or browse as a guest
- [ ] Watch a stream, follow, comment, send hearts
- [ ] Send a gift: Sparks go down; running out shows a top-up message
- [ ] Buy Sparks in Wallet: stops at the £20 daily limit
- [ ] Go Live, accept a guest, open moderation, end the stream
- [ ] Check the earnings in the summary match £0.45 per 100 Sparks
- [ ] Send a chat message, start a call
- [ ] Settings › Start the demo again resets everything

Report problems in the Issues tab with your phone model and what you tapped.
